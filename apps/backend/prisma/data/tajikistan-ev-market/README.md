# Tajikistan EV Market snapshot

## Назначение

Snapshot используется только как ориентир представленности производителей и
моделей автомобилей на рынке Таджикистана. Он не является копией объявлений и
не используется для публикации контента Somon.tj.

## Источник

- Источник: `https://somon.tj/transport/legkovyie-avtomobili/vid-topliva---6/`
- Snapshot: `somon-2026-07-31.json`
- Дата получения: `2026-07-31T00:00:00+05:00`
- Режим использования: reference-only marketplace taxonomy

Перед импортом команда показывает путь к snapshot, дату получения, количество
производителей и моделей, а также лицензионное уведомление.

## Структура

Каждая запись производителя содержит:

- `manufacturer` — название на площадке;
- `sourceUrl` — страница производителя;
- `listingCount` — справочное число объявлений на дату snapshot;
- `models` — названия моделей из фильтра площадки.

`v2-coverage-report-2026-07-31.json` содержит модели, для которых не удалось
найти строгое соответствие в проверенных международных источниках проекта.

## Запуск

Все команды выполняются из `apps/backend`:

```powershell
npm run tajikistan-ev-market:plan
npm run tajikistan-ev-market:apply
npm run tajikistan-ev-market-v2:plan
npm run tajikistan-ev-market-v2:apply
```

`plan` является dry-run и ничего не записывает. Запись возможна только при
явном `--apply`. После apply автоматически выполняется повторный plan; при
обнаружении новых записей процесс завершается ошибкой идемпотентности.

## Что не импортируется

Из Somon.tj не копируются объявления, цены, фотографии, телефоны, контакты,
описания продавцов и другой пользовательский контент. V1 использует только
названия производителей, моделей и alias. V2 создаёт поколения и спецификации
только при наличии подтверждения в разрешённых источниках проекта.
